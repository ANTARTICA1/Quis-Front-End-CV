# Interactive Front-End Curriculum Vitae (CV)

A multi-page responsive personal curriculum vitae and professional profile website built with HTML5, CSS3, and Bootstrap 5. The application outlines developer biography, educational milestones, technical competencies, and professional contact channels.

## Overview

Designed for clarity and semantic readability, this web CV organizes academic and technical credentials into structured sections. The user interface adheres to modern responsive design standards, ensuring fluid presentation across smartphones, tablets, and desktop workstations.

## Site Structure

- Home (`index.html`): High-level executive summary, professional portrait, and quick navigation.
- About (`about.html`): Detailed personal narrative, academic background at ITB STIKOM Bali, and core professional interests.
- Skills (`skills.html`): Structured technical competency matrix including programming languages, frameworks, developer tools, and operational workflows.
- Contact (`contact.html`): Direct contact portal featuring inquiry submission forms, email channels, and external professional profiles.

## Technology Stack

- Markup: Semantic HTML5
- Styling: Custom CSS3 and Bootstrap 5.3.2
- Responsive Design: Bootstrap Grid and Flexbox Utilities
- Visuals: Custom profile media and optimized styling

## Running Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/ANTARTICA1/Quis-Front-End-CV.git
   cd Quis-Front-End-CV
   ```

2. Open `index.html` in your web browser, or launch a static server:
   ```bash
   python -m http.server 3000
   ```

3. Navigate to `http://localhost:3000`.
